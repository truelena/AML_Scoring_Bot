# 🛡 AML Bot

Интеллектуальный Telegram-бот для автоматизации первичного финансового мониторинга и комплаенс-контроля (ПОД/ФТ).


## 🎯 Бизнес-логика и нормативная база
Алгоритмы оценки рисков (Green / Yellow / Red) базируются на:
* Федеральном законе № 115-ФЗ
* Положении Банка России № 860-П
* Методических рекомендациях ЦБ РФ (№ 18-МР и № 19-МР)

Система не просто реагирует на одиночные триггеры, а проводит кросс-анализ (например, *«возраст бизнеса < 6 мес» + «нематериальные услуги» + «транзит на счета физлиц»*), оценивая экономическую целесообразность операций.

## ⚙️ Ключевой функционал
* AI-Скоринг (LLM-интеграция): Анализ контекста транзакций с помощью промпт-инжиниринга и выдача структурированного JSON-ответа (Уровень риска, Триггеры, Анализ бизнес-логики, Требуемые документы).
* Ролевая модель доступа: Изолированные контуры для администратора (полный доступ) и гостевых пользователей (прямая ссылка для тестирования функционала бота предоставлена в моем резюме). Случайные пользователи блокируются.
* Аудиторский след (SQL): Логирование всех проверок в реляционную базу данных SQLite.
* Генерация отчетов: Автоматизированная SQL-выборка высокорисковых (Red) транзакций за последние 7 дней и формирование выгрузки в формате .csv по команде /export.

## 🛠 Технический стек
* Язык: Python 3.10+
* Фреймворк: aiogram 3.x (Асинхронная обработка сообщений)
* База данных: SQLite 3 (Локальное хранение логов)
* Интеграции: OpenAI API (через прокси-сервер к модели Gemini 3.1 Pro)
* Инфраструктура: Облачный деплой на серверах Amvera, управление окружением через python-dotenv.

## 🎯 Пример работы (Сценарий использования)

Входящий запрос (описание транзакции):
> "ООО 'Альфа' (зарегистрировано 2 месяца назад) переводит 2 500 000 рублей ИП Иванову А.А. за 'оказание информационно-консультационных услуг'. ИП открыт 1 месяц назад, планируется снятие средств наличными."

Ответ AML-бота (AI Scoring):
```json
{
  "risk_level": "Red",
  "triggers": [
    "Возраст бизнеса плательщика менее 3 месяцев",
    "Нематериальные услуги (консультации)",
    "Признаки транзита с последующим выводом в наличные"
  ],
  "analysis": "Высокая вероятность транзитных операций с целью обналичивания денежных средств. Присутствует классическое пересечение маркеров риска по Положению № 860-П и рекомендациям № 18-МР.",
  "action": "Ограничить ДБО, приостановить операцию, запросить подтверждающие документы по 115-ФЗ.",
  "documents_to_request": [
    "Договор на оказание консультационных услуг",
    "Акты выполненных работ с детализацией",
    "Штатное расписание или документы, подтверждающие наличие ресурсов для оказания услуг"
  ]
}
